**1. Problem Understanding**

We maintain a scroll that starts as an empty integer array. We apply $q$ operations in order:

- `1 x`: append value $x$ to the end.
- `2 x y`: replace every occurrence of value $x$ with $y$.
- `3 x y`: swap values $x$ and $y$ everywhere **simultaneously**.

After all operations, we must output:

1. The final array $S$ (space-separated).
2. The discord score of $S$, i.e., the inversion count:
$$
\#\{(i,j)\mid 1 \le i < j \le n,\ S[i] > S[j]\}.
$$

The constraints ($q \le 5 \cdot 10^5$ and values up to $5 \cdot 10^5$) require avoiding any method that scans the whole scroll for each global rewrite.

---

**2. Optimal Approach**

The solution is a two-phase method.

**Phase A: Reconstruct the final scroll by scanning operations backward**

Process operations from the last to the first while maintaining a mapping array $p$:

- $p[v]$ means: if an element is value $v$ before the already-processed suffix of operations, then after that suffix it becomes $p[v]$.

Initialize $p[v] = v$.

Backward updates:

- `1 x`: this appended element will end as $p[x]`, so record $p[x]$.
- `2 x y`: earlier $x$ becomes $y$ before the suffix, then becomes $p[y]$, so set $p[x] = p[y]$.
- `3 x y`: swapping values corresponds to swapping their outcomes, so swap $p[x]$ and $p[y]$.

The recorded list is in reverse append order, so reverse it to obtain the final scroll $S$.

**Phase B: Count inversions using a Fenwick Tree**

Scan $S$ from left to right and maintain a Fenwick Tree (BIT) over value indices:

- For current value $v$, let `seen_count` be the number of elements already processed.
- Let `prefix_sum(v)` be how many seen values are $\le v$.
- Then the number of earlier values $> v$ is `seen_count - prefix_sum(v)`, which is exactly how many inversions this element adds.

Sum over all elements to get the discord score.

**3. Code**
```python
import sys
from array import array


class IntScanner:
    """Fast integer scanner over a bytes buffer.

    Purpose:
        Parse integers from a bytes buffer using next_int().

    Args:
        data: Entire input as bytes.
    """

    def __init__(self, data: bytes) -> None:
        """Initialize the scanner.

        Args:
            data: Entire input as bytes.
        """
        self._data = data
        self._length = len(data)
        self._position = 0

    def next_int(self) -> int:
        """Return the next integer from the buffer.

        Returns:
            The next parsed integer.
        """
        data = self._data
        length = self._length
        position = self._position

        while position < length and data[position] <= 32:
            position += 1

        value = 0
        while position < length and data[position] > 32:
            value = value * 10 + (data[position] - 48)
            position += 1

        self._position = position
        return value


class FenwickTree:
    """Fenwick Tree (Binary Indexed Tree) for prefix sums.

    Purpose:
        Support point updates and prefix sum queries in O(log n).

    Args:
        size: Maximum index supported (1-indexed).
    """

    def __init__(self, size: int) -> None:
        """Create a Fenwick Tree initialized with zeros.

        Args:
            size: Maximum index supported (1-indexed).
        """
        self._size = size
        self._tree = array("I", [0]) * (size + 1)

    def add(self, index: int, delta: int) -> None:
        """Add delta to position index.

        Args:
            index: 1-indexed position to update.
            delta: Value to add.
        """
        size = self._size
        tree = self._tree
        while index <= size:
            tree[index] += delta
            index += index & -index

    def prefix_sum(self, index: int) -> int:
        """Compute sum of positions in range [1..index].

        Args:
            index: 1-indexed end position.

        Returns:
            The prefix sum up to index.
        """
        result = 0
        tree = self._tree
        while index > 0:
            result += tree[index]
            index -= index & -index
        return result


def build_final_scroll(
    operation_types: array,
    operation_from_values: array,
    operation_to_values: array,
    max_value: int,
) -> list[int]:
    """Reconstruct the final scroll by processing operations backwards.

    Args:
        operation_types: Operation types (1, 2, 3) in input order.
        operation_from_values: The x parameter for each operation.
        operation_to_values: The y parameter for each operation (0 for type 1).
        max_value: Maximum value appearing in the input.

    Returns:
        The final scroll as a list of integers.
    """
    value_mapping = array("I", range(max_value + 1))
    reversed_scroll: list[int] = []

    operation_count = len(operation_types)
    for operation_index in range(operation_count - 1, -1, -1):
        operation_type = operation_types[operation_index]
        from_value = operation_from_values[operation_index]

        if operation_type == 1:
            reversed_scroll.append(value_mapping[from_value])
            continue

        to_value = operation_to_values[operation_index]
        if operation_type == 2:
            value_mapping[from_value] = value_mapping[to_value]
        else:
            value_mapping[from_value], value_mapping[to_value] = (
                value_mapping[to_value],
                value_mapping[from_value],
            )

    reversed_scroll.reverse()
    return reversed_scroll


def count_inversions(values: list[int], max_value: int) -> int:
    """Count inversions in values using a Fenwick Tree.

    Args:
        values: Array for which to compute inversion count.
        max_value: Maximum value in values (sizes the Fenwick Tree).

    Returns:
        The inversion count.
    """
    fenwick_tree = FenwickTree(max_value)
    inversion_count = 0
    seen_count = 0

    for current_value in values:
        less_or_equal_count = fenwick_tree.prefix_sum(current_value)
        inversion_count += seen_count - less_or_equal_count
        fenwick_tree.add(current_value, 1)
        seen_count += 1

    return inversion_count


def main() -> None:
    """Read input, compute the final scroll and inversion count, and print."""
    input_data = sys.stdin.buffer.read()
    scanner = IntScanner(input_data)

    operation_count = scanner.next_int()

    operation_types = array("B")
    operation_from_values = array("I")
    operation_to_values = array("I")

    max_value_seen = 1
    for _ in range(operation_count):
        operation_type = scanner.next_int()
        from_value = scanner.next_int()
        to_value = 0

        if operation_type != 1:
            to_value = scanner.next_int()
            if to_value > max_value_seen:
                max_value_seen = to_value

        if from_value > max_value_seen:
            max_value_seen = from_value

        operation_types.append(operation_type)
        operation_from_values.append(from_value)
        operation_to_values.append(to_value)

    final_scroll = build_final_scroll(
        operation_types=operation_types,
        operation_from_values=operation_from_values,
        operation_to_values=operation_to_values,
        max_value=max_value_seen,
    )

    inversion_count = count_inversions(final_scroll, max_value_seen)

    sys.stdout.write(" ".join(map(str, final_scroll)) + "\n")
    sys.stdout.write(str(inversion_count) + "\n")


if __name__ == "__main__":
    main()
```

**4. Code Explanation**

- The program stores all operations so it can traverse them backward.
- While scanning backward, it maintains `value_mapping` where `value_mapping[v]` is the final value of an element that is currently `v` after applying the already-processed suffix.
  - For `2 x y`, it applies `value_mapping[x] = value_mapping[y]`.
  - For `3 x y`, it swaps `value_mapping[x]` and `value_mapping[y]`.
  - For `1 x`, it records `value_mapping[x]` as the final value of that appended element.
- After reversing the recorded list, we obtain `final_scroll`.

Then the inversion count is computed using `FenwickTree`:

- When processing `current_value`, `prefix_sum(current_value)` gives the number of earlier values $\le$ it.
- So the number of earlier values $>$ it is `seen_count - less_or_equal_count`, which is added to the answer.

Small illustration of Phase A logic:

- Suppose the remaining suffix mapping currently implies $p[1]=5$ and $p[3]=2$.
- Encountering `1 3` while scanning backward records `2` (because that appended 3 ends as 2 after the suffix).

---

**5. Time and Space Complexity**

Let $n$ be the number of append operations (final scroll length) and $M$ be the maximum value appearing in input.

- Time:
  - Backward reconstruction: $O(q + M)$
  - Inversion counting with Fenwick Tree: $O(n \log M)$
  - Total: $O(q + M + n \log M)$
- Space:
  - Operations storage, mapping array, Fenwick tree, and the final scroll:
    $O(q + M + n)$

---

**6. Conclusion**

Processing operations backward with a value-mapping array avoids expensive full-scroll rewrites, and a Fenwick Tree computes the discord score efficiently. This combination meets the constraints for $q \le 5 \cdot 10^5$ while producing both the final scroll and its inversion count.
